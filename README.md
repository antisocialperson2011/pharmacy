# 💊 Аптека «Лирика»

### Приложение для аптечной сети на Windows Forms

**Каталог лекарств · Корзина · Оформление заказа · Админ-панель**

</div>

---

## ✨ Возможности

### 🛒 Клиент
- Просмотр каталога, поиск по названию, фильтр по категории
- Добавление в корзину с выбором количества (двойной клик по товару тоже работает)
- Проверка остатков на складе: нельзя заказать больше, чем есть
- Изменение количества (+/−), удаление позиций, очистка корзины
- Выбор аптеки самовывоза и способа оплаты
- Оформление заказа с подтверждением
- История заказов с составом каждого заказа
- Отмена заказа в статусе «Новый» (товар возвращается на склад)

### 🛠 Администратор
- Добавление, редактирование и удаление товаров
- Управление ценами и остатками, массовое изменение всех цен на N %
- Просмотр всех заказов, смена статусов: `Новый → Собран → Выдан` или `Отменён`
- Отмена заказа автоматически возвращает товар на склад
- Сводка: количество заказов и общая выручка
- Управление пользователями: смена роли, удаление

### 🔑 Для всех
- Вход и регистрация, набор функций зависит от роли
- Выход из аккаунта без закрытия программы
- Единое фирменное оформление в зелёных тонах

---

## 🔐 Тестовые аккаунты

| Роль | Логин | Пароль |
|---|---|---|
| 👑 Администратор | `admin` | `admin123` |
| 🙋 Клиент | `client` | `client123` |

Новые пользователи регистрируются на экране входа и получают роль **клиента**. Пароли хранятся в виде SHA-256-хэшей, а не открытым текстом.

## 🚀 Запуск

**Требования:** Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

### Через Visual Studio 2022
1. Установить **«Разработка классических приложений .NET»**.
2. Открыть файл `PharmacyPro.csproj`.
3. Запустить сборку нажатием клавиши **F5**.

### Через терминал
```bash
cd PharmacyPro
dotnet run
```

## 🗂 Структура проекта

```
📁 PharmacyPro/
 ├─ PharmacyPro.csproj
 ├─ Program.cs        точка входа, цикл «вход → рабочее окно → выход»
 ├─ Models.cs         User, Product, CartItem, Order, OrderLine, Role
 ├─ Db.cs             хранилище данных (JSON), хэширование паролей
 ├─ Theme.cs          цвета, шрифты, кнопки, таблицы, базовая форма ShellForm
 ├─ LoginForm.cs      вход и регистрация
 ├─ ClientForm.cs     окно клиента
 └─ AdminForm.cs      окно администратора
```

## 🧱 Архитектура

```
 ┌────────────┐     ┌──────────────┐     ┌────────────────┐
 │ LoginForm  │ ──► │ ClientForm   │     │                │
 │ (вход)     │     │ AdminForm    │ ──► │   Db (JSON)    │
 └────────────┘     └──────────────┘     │ Products       │
        ▲                  │             │ Users          │
        └── «Выйти» ───────┘             │ Orders         │
                                         └────────────────┘
```

- **Формы** только показывают данные и реагируют на действия пользователя.
- **Models.cs** описывает данные и не знает про интерфейс.
- **Db.cs** хранит всё в одном JSON-файле и сохраняет изменения после каждой операции.
- **Theme.cs** собирает оформление в одном месте, чтобы менять внешний вид централизованно.
